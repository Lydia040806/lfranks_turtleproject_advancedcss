# All About Turtles

A one-page HTML website introducing turtles, built with plain HTML and internal CSS.

## Features

- Heading levels 1-3, paragraphs, and an unordered list
- Two centered images
- Four links to Wikipedia articles about turtles
- Horizontal rules and a copyright notice

## Usage

Open `index.html` in a web browser.

Live site: https://lydia040806.github.io/All-About-turtles/
